## 5. 顺带修掉的真 bug

`mk-verify.sh` 初版用了 `grep -c 'a\|b'`。

**Android toybox grep 不支持 BRE 转义 `\|`** → 静默返回 0。

后果：会用**错误的校验脚本**得出"功能不存在"的结论 —— 与事故本身同构的陷阱。

已全部改为 `grep -cE 'a|b'`。

### 同类坑（值得记住）

| 写法 | toybox grep | 说明 |
|---|---|---|
| `grep -c 'a\|b'` | ❌ 返回 0 | BRE 转义不被支持 |
| `grep -cE 'a|b'` | ✅ 正确 | 用 -E |
| `grep -c 'a' ; grep -c 'b'` | ✅ 正确 | 分开跑 |
