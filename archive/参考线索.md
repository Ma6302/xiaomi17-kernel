## ⛔ 线索 1：朋友的内核仓库 —— 已定性，**不再跟进**

```
仓库：https://github.com/StarfallSeas/android_kernel_sm8850_xiaomi_common
分支：android16-6.12.90-2026-07-24   （唯一分支）
HEAD：b546349ae4897647120a20445af230e80ca9c068
标签：无
状态：作者无设备；产物开不了机
```

### 更正：它**不是**厂商整机树（前次记录有误，2026-10-07 实测推翻）

| 检查项 | 实测结果 |
|---|---|
| 根目录 | 含 `gki/`（含 `gki/aarch64/abi.stg`、`abi.stg.allowed_breaks`、`afdo`） |
| build config | 含 `build.config.gki`，Kleaf / Bazel 布局 |
| `arch/arm64/configs/` | **只有 `gki_defconfig`**，无 pudding/canoe 厂商 defconfig |
| `arch/arm64/boot/dts/qcom/` | 全为上游公版 dts（msm8916/8996/…），**无 pudding dts** |
| 分支命名 | `android16-6.12.90-2026-07-24` = ACK 发布分支格式 |
| CI (`build.yml`) | `BUILD_TAG="android16-Catalyst-StarfallSeas-…"`，用 `gki_defconfig` + clang r536225 编 `Image` |

**结论：它是 AOSP ACK `kernel/common` 的 `android16-6.12.90` 快照
+ 若干 sched/block 优化补丁（PELT 半衰期 32→16ms、fair 均衡更新 CPU 容量、
UFS 强制 none 调度器、try_to_wake_up 修复等）+ 一套 GitHub Actions CI。
仓库名里的 `xiaomi_common` 起得有误导性。**

### 处理决定（用户 2026-10-07 明确指示）

- **不引入、不深究、不采用**。作者没有设备，产物开不了机，
  若把它的结论当依据会把我们带偏。
- 它「不开机」与其路线无关 —— 因为它的路线**和我们的完全同源**
  （同为 ACK + `gki_defconfig` + clang r536225）。所以
  「厂商树不开机 → 佐证 GKI 路线」这条推论**作废**（前提本身就是错的）。
- 失败原因未定位，属于 UNKNOWN，不猜。

### 唯一保留的可取之处

其 CI 用的工具链来源**实测可用**：

```
https://github.com/cctv18/oneplus_sm8650_toolchain/releases/download/LLVM-Clang19-r536225/
  ├── clang-r536225.zip
  ├── rust.zip          ← rustc 1.82.0-dev + bindgen 0.69.5
  └── build-tools.zip   ← 含 AOSP 版 pahole 与 mkbootimg 系列
```

本轮（2026-10-07）Rust 与 build-tools 即取自此处，实测：
- `rustc 1.82.0-dev (f6e511eec 2024-10-15) (Android Rust Toolchain version linux-12909517)`
- `bindgen 0.69.5`

两者与**真机内核**的 `CONFIG_RUSTC_VERSION_TEXT` / `CONFIG_BINDGEN_VERSION_TEXT`
**逐字一致**，是正确工具链。

## 线索 2：torvalds/linux

```
https://github.com/torvalds/linux
```

**用途**：上游 Linux 主线。

- 我们用的 **6.12 LTS 上游** 就是它的 `linux-6.12.y` 分支 / tag `v6.12.x`
- **不用来直接构建**（不含 Android/GKI 补丁）
- 用途：
  - 查某个函数的**上游原始实现**（判断厂商改动）
  - 查某功能是**哪个版本引入的**
  - 比对 kernel.org 的 stable 补丁

**已有更直接的上游源**：
```bash
# 官方 stable（已实测 ~1.4MB/s）
https://cdn.kernel.org/pub/linux/kernel/v6.x/linux-6.12.tar.xz
```
